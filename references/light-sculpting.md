# 光影塑形

## 为什么这一步不能省

全局参数只能定一个「整体的明暗倾向」，它不知道画面的哪个面朝光、哪条沟是凹的、
哪块石头在前。**光影塑形是把照片从"调过曝光"变成"有体积"的唯一手段。**

省掉这一步的典型结果：参数看起来很对（对比够、黑白场到位、不溢出不发灰），
但画面是平的，像一张印刷品。用户会说「还不如我自己修的」——因为他自己修的时候，
哪怕是随手拉渐变，也在做某种程度的分区。

## 全局和蒙版不是二选一

这是最容易走偏的地方，两个方向都试过，都错：

| 走偏的方向 | 表现 | 后果 |
| --- | --- | --- |
| 只堆蒙版 | 17 层局部曝光去模拟整体明暗 | 层间互相抵消，改一层动全身 |
| 只做全局 | 参数干净、对比到位，但不做分区 | 画面平，没有体积，像印刷品 |

**正确关系：全局定基调 → 蒙版做塑形 → 蒙版不改基调。**

判断标准很清楚：
- 全局负责「这一类亮度整体往哪走」（高光压多少、阴影提多少、对比多强）
- 蒙版负责「这个面为什么比别人亮」（朝光、在前、是凹陷还是凸起）

一条经验：**一张有明确光向的风景片，做完全局之后至少还需要 4–8 层光影，
否则基本可以判定没做完。**

## 先定光向，再定每一层的正负

光向错了，后面全是反的。判据（按可靠性排序）：

1. **最暖最亮的地面带朝向**——太阳所在方位
2. **物体受光面的一致性**——树干、石头、坡面，亮的那一侧朝着谁
3. **影子方向**——影子指向光源的反方向
4. **天空最亮处**——通常贴着地平线，指向光源
5. **远山的冷暖**——顺光时远山偏暖偏亮，逆光时偏冷偏暗

定好之后，每个面的符号就确定了：

| 面 | 处理 |
| --- | --- |
| 朝向光源的坡面 | 提亮 + 加暖 + 提饱和 + 提清晰度 |
| 背向光源的坡面 | 压暗 + 加冷 + 降饱和 |
| 脊线／棱边 | 窄带提亮（受光棱） |
| 沟壑／凹陷 | 压暗（凹处见不到光） |
| 背光的物体轮廓 | **不要加勾边光**，这是最常见的假 |

## 分层模板

一套通用的光影层，按顺序加，每加一批导出验证：

### 1. 主受光面
整张片子里最亮的那块受光区，通常是坡面、草甸、岩壁。

```
径向 覆盖受光区     EV +0.15 ~ +0.25
                    temp  +6 ~ +12
                    sat   +8 ~ +12
                    clarity +6 ~ +10
```

不要一次给到 +0.4，会和二值化一样假。

### 2. 主背光面
和受光面相邻的暗面，是制造体积的关键。

```
径向 覆盖背光区     EV −0.12 ~ −0.22
                    temp −4 ~ −8
                    sat  −4 ~ −8
```

受光面和背光面的**落差做到 0.35–0.45 EV**，体积就出来了。低于 0.25 看不出，
高于 0.6 会假。

### 3. 脊线与棱边
一条窄带，贴着山脊、坡棱、岩石棱边。

```
线性/窄椭圆 沿棱线   EV +0.10 ~ +0.18
Feather 25–35（要窄，55 会摊平）
```

这是最提气的一层，但最容易露破绽。宁可窄一点、轻一点。

### 4. 沟壑与凹陷
`EV −0.10 ~ −0.18`，只压局部，不要连成一片。
用 2–3 个小径向各自压一条沟，比一个大蒙版压整片自然。

### 5. 远山加雾（大气透视）
```
径向 覆盖远山        EV +0.10 ~ +0.15
                    contrast −8 ~ −12
                    temp −6 ~ −10
                    dehaze −5 ~ −10
```
负去雾 = 加雾。远山要**更亮、更冷、对比更低**，这是纵深的一半。

### 6. 天空的暖霞
贴着地平线或云层边缘的暖色，用蒙版局部加，**不要动全局 Tint**。

```
径向/线性 覆盖霞区   ev +0.03 ~ +0.06
                    temp +12 ~ +16
                    tint +10 ~ +13
                    sat  +8 ~ +12
```

全局改 Tint 会把整张片子的色彩倾向带跑，局部加才是对的。

### 7. 前景锚点
挑 1–2 块主石或主草丛提亮，给眼睛一个落脚点。

```
径向 覆盖单块主体    EV +0.15 ~ +0.20
                    clarity +10 ~ +14
                    texture +6 ~ +10
```

### 8. 前景暗框
底部/边缘压暗，把视线往画面中间推。

```
线性 zero(y=0.55) → full(y=1.05)   EV −0.12 ~ −0.16
```

## 动物主体：Dodge & Burn 的正确理解

查过五篇野生动物后期资料（animalstart / frameandfocal / skeysimages /
jayantaguha / naturettl），共识很清楚：

**Dodge & Burn 是「局部的明暗塑造」，不是「把主体整体提亮」。**

原话：「burn down parts of the image that you want to de-emphasize and dodge
areas that you would like to emphasize」——压暗要淡化的，提亮要强调的。

### 一条最容易犯的逻辑错误

**「AI 主体 +0.1 EV」+「AI 反选 −0.12 EV」= 「提主体 + 降全局曝光」。**

数学上完全等价，绕了一圈还多两层蒙版。如果主体本来就不暗，这个组合纯属浪费。

正确分工：
- **整体曝光定在「背景合适」的水平**（背景不需要靠蒙版压）
- **主体亮度靠一个 AI 主体蒙版校正**（只给 clarity/texture，或极小 EV）
- **剩下的全是主体内部的塑形**

如果发现「背景发黑」，先查是不是自己压出来的，不是先加曝光。
实测：一张蛇片，背景 47.7 觉得黑，把 5 层压暗全关掉、只留全局，
背景立刻回到 53.4，曝光根本不需要加那么多。

### 光衰减原则（最实用的一条）

资料原话：「burn shadows where light naturally falls away:
behind ears, under chins, along ribcages」——**在光自然消失的地方压暗**。

对一条盘曲的蛇，就是**每一段身体的下侧**各压一个：

```
颈下        −0.22
前段下      −0.20
竖段外侧    −0.18
底段下      −0.20
Feather 35–40（要窄，宽了会糊成一片）
```

四段各自独立，**不要用一个大的径向压一整片**——那是涂灰。

### 眼睛

多篇一致：**提亮虹膜上下缘和反光点，压暗瞳孔，不照整只眼**。

LR 里一个径向做不到分开提亮虹膜和压暗瞳孔，退一步用**小径向只包眼球**：
`+0.20 ~ +0.25 EV、clarity 25–30、Feather 30`。
瞳孔本来就黑，不会被提过头，效果接近。

眼睛的框要非常小（约为画面宽度的 3%），偏一点就打到鳞片上，会露馅。

### 幅度纪律

- 笔刷 8% 不透明度、5% 流量，**任何区域不超过 3 遍**
- 超过会出现「辉光」，100% 放大可见
- 有资料提到：某自然摄影奖投稿里 92% 的过度修图能被评委检出

LR 里没有笔刷遍数概念，等效做法是**单层 EV 不超过 0.25，靠多层累积**。

### 背景不要压太黑

资料原话：「lower exposure on the background to make the animal stand out,
but use a luminance mask to protect the sky from getting too dark」。

实测反面：一条蛇片叠了 5 层压暗（−0.12 / −0.08 / −0.10 / −0.12 加接触影），
背景压到 47.7，观感「压抑」。减到 −0.06 一层后回到 53.4，主体反而更突出——
因为主体和背景的对比靠「主体亮」和「背景暗」共同构成，压死背景等于毁掉一半信息。

### 白平衡：不要多层降温叠加

背景层 `temp −4`、加雾层 `temp −9`，两处叠加后水面直接发蓝。
实测水面 B−R 从 −30.5（自然偏暖）跑到 +30（发蓝）。

**规矩：全片只允许一处降温**，其余层不碰 temp。
修正后水面 B−R 回到 −24.4，暖回来了。

## 主体塑形三件套（人像 / 野生动物标准做法）

只做"光衰减"（把主体下侧压暗）是**压暗，不是塑形**。真正让主体立起来的是三件事：

### 一、轮廓光（Rim Light）—— 靠 clarity，不靠 EV

沿主体**上缘**（朝光的那条边）加一道窄带，模拟顶光勾勒轮廓。

**关键：不要指望用 EV 提亮。**

实测（ZTY_6198 绿蛇）：蛇本身亮度已经 130–150，接近高光区，
给上缘 +0.22 EV 几乎看不出变化——被高光压缩吃掉了
（同一个病：之前给 145 的颈顶 +0.12 只出 +1.4）。

**正确参数**：

```
径向 覆盖上缘窄带（宽度约主体厚度的 1/5）   Feather 22–28
     EV      +0.12 ~ +0.18      ← 只给一点，别指望它出效果
     clarity +16 ~ +20          ← 真正起作用的是这个
     texture +12 ~ +16
```

clarity 增加局部中间调对比，让鳞片/毛发的边界变清楚，**亮度不用变就有"被光勾边"的感觉**。

### 二、核心阴影（Core Shadow）—— 立体感的主要来源

既然上缘提不动，**立体感就靠下缘压深**。

```
径向 覆盖下缘（宽度约主体厚度的 1/3）   Feather 28–32
     EV −0.36 ~ −0.45
```

实测：−0.20 时蛇身只降 0.7（几乎看不出）；−0.42 时才真正"圆"起来。
**同一个主体要做多段**——蛇盘三圈就是 4 段，每段各一个，不许用一个大框压一片。

### 三、接触阴影（Contact Shadow）—— 让主体"坐实"

压在主体与承载面的交界**外侧**（属于背景，不是主体）。

```
背景 ∩ 窄带（紧贴主体下缘外侧）   Feather 35–45
     EV −0.22 ~ −0.30
```

没有这条暗带，主体是"浮"在表面上的；有了才是"压"着的。

### 三件的分工

| 手法 | 位置 | 作用 | 主要参数 |
| --- | --- | --- | --- |
| 轮廓光 | 主体上缘 | 勾出边界、出质感 | **clarity / texture** |
| 核心阴影 | 主体下缘 | 出圆柱体积 | **EV −0.36~−0.45** |
| 接触阴影 | 主体外缘地面 | 坐实、不悬浮 | EV −0.22~−0.30 |

## 背景造光（用户：「背景也要重塑出光来突出主体」）

单独给背景一块区域提亮，**看不出"光"**——那只是一块稍亮的苔藓。

**光感需要三件套，缺一不可：**

| 件 | 写法 | 给出什么 |
| --- | --- | --- |
| **斜射光带** | **线性**渐变，zero 在光源侧、full 在对侧，+0.15~+0.25 | "光从哪来" |
| **光热点** | 小径向（Feather 40 左右），+0.24~+0.35 | "光落在哪" |
| **反向压暗 + 暗角** | 与光源相对的一侧压 −0.14~−0.20；四角 −0.05~−0.08 | "光没照到哪" |

实测对比：
- 只做光池（圆形径向 +0.34、Feather 65）→ 视觉上几乎看不出，像苔藓本来就这么亮
- 换成**线性斜射光带 +0.20 + 小光热点 +0.26 + 左下压暗 −0.16** → 才出现"光从右后方来"的感觉

**光带方向必须和画面真实光向一致**（看最亮的面朝哪、影子往哪倒）。
方向错了会比不做更假。

## 压基础曝光 + 局部光重建

人像后期的常用手法：**先把整体压暗一点，再用局部光把主体"打"出来**。

```
全局 Exposure  −0.04 ~ −0.08（从当前值降）
然后主体轮廓光、背景光热点的相对亮度才有空间
```

实测：ZTY_6198 从 Exposure 0.45 降到 0.41，蛇立刻从"和苔藓一样亮"变成"被光托着"。

**边界**：不能压过头。试过降到 0.36 → 全图 −17.1%、中位掉到 48，画面发闷，
回退到 0.41。判据：中位仍在 45–70，死黑不涨超过 1 个百分点。

## 主体塑形：接触阴影比提亮更重要

拍一个有明确主体的片子（动物、昆虫、石头、一棵树），最容易犯的错是
**只给主体提亮**——结果主体是亮了，但像贴纸一样浮在背景上。

**主体「实不实」，取决于它和承载它的东西之间有没有投影。**

### 判断方法

放大到 100%，看主体和地面的交界：

- 交界处有一条明显的暗带 → 主体是「压」在上面的，实的
- 交界处直接是主体亮色 → 背景色 → 主体是「浮」的，假的

自然光下，任何物体压在另一个表面上都会产生接触阴影，哪怕光很软。
没有这条暗带，大脑就判定它是合成的。

### 做法

**不要用一个大蒙版压一片**，那是「涂灰」，不是塑形。要在**每一个接触点**
各放一个小径向，Feather 35–45：

```
径向 覆盖接触带（宽度约主体宽度的 1/2）   EV −0.18 ~ −0.24
                                            sat −6 ~ −10
```

一条盘曲的蛇需要 3 个：头颈下、身中段下、尾下。
一块石头需要 1–2 个：底边、与相邻石头的缝隙。

总量控制：所有接触阴影加起来，不能让整体亮度掉超过 3%。
它们面积小，主要作用是"勾"出边界。

### 配套：主体的顶面高光

接触阴影做完，主体会显得沉。补一层顶面高光把它"抬"起来：

```
径向 覆盖主体朝光的上表面    EV +0.08 ~ +0.12
                            clarity +18 ~ +22（鳞片、纹理、毛发的质感）
                            texture +10 ~ +12
```

一压一提，主体就有圆柱感/球感，不再是平的。

### 顺序

1. **AI 主体**给整体质感和微提亮（`+0.05 ~ 0.15`，主体本来亮就别提）
2. **AI 主体反选**压背景
3. **接触阴影**（3–4 个小径向）
4. **顶面高光**（1 个）

第 3、4 步是「主体内部的光影」，不能和第 1 步合并——第 1 步是整体，
第 3、4 步是局部，混在一起调不出来。

### 实测

一条翠绿色的蛇盘在苔藓上：

| 版本 | 全图 | 蛇/背景对比 | 观感 |
| --- | --- | --- | --- |
| 原片 | 56.6 | 1.90 | 蛇和苔藓混在一起 |
| 只做主体+背景分离 | 57.3 | 2.10 | 蛇跳出来了，但浮着 |
| **再加 3 个接触阴影 + 颈顶高光** | **57.2** | 2.10 | **蛇压在苔藓上，有体积** |

注意：加接触阴影后全图亮度几乎没变（57.3 → 57.2），
但观感差别很大——**这说明它不是靠改亮度起作用，是靠改明暗关系**。

## 检查这四件事

1. **相邻两个面的 EV 差够不够 0.35？** 不够就是平的，够了才有体积
2. **蒙版边界看不看得见？** 放大到 100%，沿边界扫一遍。凡是能画出边界的地方，Feather 不够或力度太大
3. **光向自洽吗？** 受光面全在一边，背光面全在另一边。有一块反了就是假的
4. **暗部还看得见东西吗？** 背光面压到 30 以下就要小心，那里应该是暗但有细节，不是死黑

## 一个完整的配比示例

傍晚侧逆光的山坡场景（实测）：

```
全局：Contrast 3 / Highlights −66 / Shadows +46 / Whites −22 / Blacks +22 / 缓 S 曲线
层1 前景暗框    EV −0.14
层2 山坡受光带  EV +0.22  temp +8  sat +10  clarity +8
层3 坡面背光    EV −0.18  temp −6  sat −6
层4 远山加雾    EV +0.12  contrast −10 temp −8 sat −8
层5 前景主石    EV +0.18  clarity +12 texture +8
层6 杨树亮部    EV +0.10  sat +6  temp +5
层7 天空暖霞    EV +0.04  temp +14 tint +12 sat +10
```

结果：坡顶金光 119.3、坡中 63.2，落差 56；全图亮度只比原片高 1.9%，
死黑 1.13%。**没有一块是死黑，但每个面都分开了。**
