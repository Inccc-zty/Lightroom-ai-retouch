# 审美判据

## 用户反馈速查（原话 → 真正的问题 → 该动哪里）

| 用户说 | 真正的问题 | 该动 |
| --- | --- | --- |
| 「对比度太高」 | Contrast 太大，或暗部被压死 | 降 Contrast、放松曲线、先看死黑 |
| 「太压抑 / 背景太黑」 | 压暗层叠太多 | 撤压暗层；先查是不是自己压出来的 |
| 「水都蓝的」 | 多层 temp 叠加 | 全片只留一处降温 |
| 「有点偏红」 | 暗部被 Shadows 抬起，红色浮出 | 降 Shadows，不是降饱和 |
| 「还不如我自己修的」 | 全局把原片好基调改坏了 | 并排对比，退回接近原片 |
| 「蛇偏黄」 | 给主体加了 sat，或 clarity 过头 | 撤 sat；clarity 降到 15 以内 |
| 「头没区别」 | 提亮无效——那块已接近高光 | 去压暗旁边更亮的地方，别再提头 |
| 「背景也亮了」 | 几何蒙版不认物体边界 | 改布尔：主体 ∩ 框 |
| 「蒙版不准」 | 同上 | 同上，并导出差异图验证 |

**共性**：用户的反馈几乎都是「关系错了」，不是「某个数值错了」。
先找关系（谁该比谁亮、谁该比谁暗），再动数值。

## 第一条：量化只能定位，不能裁判

**用算术平均 RGB 判断明暗是错的。** 深绿植被 R 低、G 高、B 低，算术均值天然偏低，
但感知亮度并不低。用 Zone 分布量深绿树林，会得到「91% 堆在暗区 = 一片近黑」的结论，
放大一看，实际比原片更浓更透。

正确做法：
- 判亮度用 **Rec.709 加权**：`L = 0.2126R + 0.7152G + 0.0722B`
- 判对比度用**归一化**：`CV = σ / mean`，绝对 σ 会让暗部天然偏低
- 判色调用**视觉模型看画面**，不要算 RGB。RGB 只能告诉你「红在哪里」，
  不能告诉你「是不是太红」。定位手段：把可疑像素涂色叠加，一眼看出问题在哪个物体上

**指标会说谎，眼睛不会。** 一张片子数字全达标但看着闷，就是闷。

## 第二条：层次感的本质是「台阶」，不是「斜坡」

一张片子从天空到前景的亮度如果这样走：

```
190 → 164 → 113 → 105 → 90 → 89 → 77 → 63 → 50 → 36
```

看起来很「规整」，单调递减，但**它就是平的**。因为相邻层只差 10–15，
人眼感知不到分层，只看到一条连续斜坡。

有层次的片子是这样的：

```
190 → 164 → 113 ─┐
                 └→ 70   ← 断层，落差 40+
      83 ─┐
          └→ 61   ← 断层，落差 22
```

**层与层之间需要 20–30 的跳跃**，才能被感知成「两个面」而不是「一个渐变」。

实操：不要追求整条梯度好看，去盯**关键交界处的落差**。
远山与谷底的交界、谷底与石滩的交界、石滩与草的交界，每一处做 20+ 的落差，
层次自然就出来了。

## 第三条：大气透视——远的东西更淡，不是更暗

空气散射会把远处的暗部提亮、色彩冲淡、对比降低。所以：

| 属性 | 远处 | 近处 |
| --- | --- | --- |
| 亮度 | 更亮 | 更暗 |
| 饱和 | 更低 | 更高 |
| 对比 | 更低 | 更高 |
| 色温 | 更冷 | 更暖（受光面） |

参数方向：远山 **曝光 +、色温 −、对比 −、去雾 −**（负去雾 = 加雾）。

**踩过的坑**：为了让远山「后退」，给它压 EV。这是反的——压暗会让它往前扑，
把层级压平。实测证据：一张傍晚山谷片，远山感知亮度 99，中景 96，
远山确实比中景**亮**，这才符合大气透视。

## 第四条：逆光和顺光，远山的方向相反

这是最容易搞错的一条。

| 光线 | 远山处理 | 原因 |
| --- | --- | --- |
| **顺光/侧顺光** | 远山**提亮**、降饱和、降对比、加冷 | 空气散射把远处提亮 |
| **逆光/剪影** | 远山**压暗**、降饱和，做成剪影 | 太阳在场景背后，远山是背光面 |

判断方法：看地平线附近最亮最暖的那块，那就是光源方向。
光源在画面之外的正前方 → 逆光；光源在相机背后 → 顺光。

**踩过的坑**：把一张逆光片当顺光片修，把远山从 74 提到 107，
结果远山比中景还亮，剪影没了，整张片子像被雾糊住。
正确做法是压到 90 左右，与天空形成硬边，才是逆光该有的分离。

逆光片还有一个标志：**地平线附近应该有一条明显的暖光带**，
这是太阳贴地平线的散射光。没有这条带，逆光感就不成立。

## 第五条：光从哪来，决定每个面该亮还是该暗

先定光向，再定每一层的正负号。定错光向，后面所有蒙版都是反的。

判断线索：
1. 天空最亮最暖的区域 = 光源方位
2. 石头的受光面朝向 = 光源方位
3. 树冠/坡面的亮边在哪一侧
4. 影子的方向（影子指向光源的反方向）

定好之后：
- 朝向光源的坡面 → 提亮、加暖
- 背向光源的坡面 → 压暗、加冷
- 与光源同侧的前景 → 可以有受光面
- 背光面**不要加勾边光**。这是常见错误：为了「让坡有立体感」给背光坡加轮廓光，
  结果光向自相矛盾，看起来假。背光面就该是暗的、简单的、让位的。

## 第六条：前景的作用是「框」，不是「主体」

前景太亮会抢戏，前景太暗会闷。它的正确定位是**视觉框架**：

- 底部/边缘压暗 → 把视线往画面中间推
- 前景里挑 1–2 块**受光面**提亮 → 给眼睛一个落脚点
- 其余部分保持暗、低饱和

实操数据（一张山谷片的前景石滩）：
- 主石提亮到 83.7，周围石滩压到 61.0，**落差 22.7** → 石头有体积
- 底部草压到 34.5 → 形成暗框
- 全图只降了 4.7%，但层次感明显提升

**关键：拉开落差，不是整体压暗。** 想做出「中景/前景 = 1.8」的比值，
去提亮中景（分子变大），不要压前景（分母变小）。压分母的代价是整张片子变暗，
比值达标了但观感更差。

## 第七条：细节靠 clarity / texture，不靠提亮

暗部「没细节」的直觉反应是加曝光，但加曝光会让暗部变灰、失去剪影。

正确做法：
- 想要暗部有内容 → `Clarity +12~26`、`Texture +8~20`，只加中频对比，不抬亮度
- 想要暗部更沉 → 降 `Shadows`、压 `Blacks`，让最暗处真正落地
- 两者可以同时做：暗部更暗但纹理更清楚

## 第八条：先修全局，再修局部

顺序反了的典型症状：全局 `Shadows +45` 把所有暗部抬起来，
你在局部压 −0.2 EV，净效果几乎为零，然后以为「蒙版没生效」。

检查顺序：
1. `CameraProfile` 是不是 `Flat`（最平配置）
2. `Shadows` 是不是大幅正值
3. `Blacks` 是不是接近 0
4. `Contrast` 是不是小于 10
5. 曲线是不是空的

这五项任意一项不对，局部怎么调都是白费。

**但「先全局」不等于「只做全局」。** 全局修完只是把基调摆正，
画面仍然是平的——因为它不知道哪个面朝光。全局之后必须补 4–8 层光影塑形，
做法见 `light-sculpting.md`。

只做全局的成品有个共同特征：参数挑不出毛病，但看着像印刷品。
这时候不要怀疑全局参数，是缺了塑形这一步。

## 第九条：全局做关系，蒙版做位置

这条排在其他条前面也不为过。**绝大多数「层次感不够」的问题，答案在全局滑块里，不在蒙版里。**

理由很简单：蒙版的作用是「让这个位置和同亮度的其他地方不一样」。
如果你要的只是「暗部更暗、亮部更亮」，那是曲线和黑白场的活，
用蒙版去做等于手工画一条曲线，还画不准。

判据：

| 你在做什么 | 应该用 |
| --- | --- |
| 让**某一类亮度**变化 | 全局（高光/阴影/白场/黑场/对比/曲线） |
| 让**某个位置**和同亮度的其他地方不同 | 蒙版（光向、主体、分区） |

典型误区：用 17 层局部曝光去模拟「高光压低、暗部下沉」，
结果每层都在和别的层抵消，改一层动全身，想调方向就得重算十几层。
换成全局 7 个参数，云层更厚、石头不偏色、层次更干净，而且改一个滑块就能整体转向。

**全局骨架的参考量级（逆光风光）**：

```
Exposure   +0.26     补亮度，不要靠降对比去换
Highlights -70       云层沉下去
Shadows    +26       暗部留一点透
Whites     +6        白场提起来，画面才通透
Blacks     -13       黑场落地
Contrast   +15       骨架
```

一组推过头的记录：`Highlights -78 / Shadows 16 / Blacks -20 / Contrast 20`，
全图掉 14.7%、死黑 9.17%，超出警戒线，必须回撤。

**蒙版该出手的四种场合**：
1. 光向造成的左右不对称（同一亮度，位置不同）
2. 全局分不开的亮度过界重叠（天空太亮但地面刚好）
3. 单块主体的主次（挑一块石头做视觉锚点）
4. 交界处需要干净（AI 天空贴树冠）

除了这四种，先问全局。

## 第十条：色调要克制

「太红了」是高频反馈。常见成因是三重叠加：

1. 提亮暗部 → 暗部的红色被抬出来
2. HSL 橙色/黄色加饱和 → 草地和石头变暖
3. 局部加暖蒙版 → 再叠一层

三个都做，必然过火。**排查方法**：把可疑像素涂色叠加，看红色集中在哪个物体上。
曾经以为偏红来自石头，涂色后发现是草地被染红——因为草地占面积大，
HSL 橙色加饱和影响的是它。

修正方向：降 HSL 橙/黄的饱和，去掉局部加暖，用 `Vibrance` 补回生机
（Vibrance 会保护已经饱和的颜色，比 Saturation 安全）。

## 判断清单（每步问自己）

1. 这一步的目标是什么？哪个区域从多少变到多少？
2. 光向对不对？这个面该亮还是该暗？
3. 是「台阶」还是「斜坡」？落差够不够 20？
4. 有没有和别的层叠加过头？总 EV 是多少？
5. 放大看，有没有接缝、光晕、假亮？
6. 整体有没有变暗超过 15%？
7. 数字说达标了，但我自己看着舒服吗？
