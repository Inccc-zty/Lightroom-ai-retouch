# 完整案例：从诊断到定稿

规则是抽象的，案例是可复现的。这一份记录三张照片的**完整路径**——
诊断数据、全局参数、每一层蒙版在做什么、实测结果、以及复盘时发现的错误。

读法建议：不要抄参数。看的是**为什么这么判断**，以及**哪一步走错了**。

---

## 案例 A：同色系 · 绿蛇在苔藓上

**照片**：竹叶青盘在长满苔藓的岩石上，带一挂小瀑布。主体占幅约 15%。

### 诊断（零状态实测）

| 项 | 主体（蛇） | 背景（苔藓） | 结论 |
| --- | --- | --- | --- |
| 亮度 L | 116 | 114 | **比值 1.02，明度几乎不分** |
| 饱和度 | 0.807 | 0.795 | 几乎相同 |
| R−B（暖冷） | 30.1 | 14.0 | 色差 16.1，成立但弱 |

**六把刀判定**：明度 ✗、色相 ○（弱）、饱和 ✗、质感 ✓、焦点 ✗、空间 ✓（但禁止改构图）。

→ 只能用**饱和度 + 冷暖 + 质感**。这是最难的场景类型：主体和背景同色系。

### 全局（九步，归零后重做）

```
CameraProfile = Camera Standard     # 动物题材必须，Adobe Standard 会把苔藓绿压成灰黄
Exposure2012  = +0.83               # 中位 31.8 → 49.2
Temperature   = 5106, Tint = 11     # 不动：全图最低饱和仍有 0.344，没有可信中性参考
Whites = +14, Blacks = −3
Highlights = −16, Shadows = +5
Contrast = +5
ToneCurvePV2012 = [0,0, 40,36, 96,93, 152,158, 208,215, 255,255]
SharpenEdgeMasking = 45
```

### 18 层蒙版

| 组 | 层 | 参数 | 在做什么 |
| --- | --- | --- | --- |
| 分离 | 01 主体质感 | clarity +12 / texture +10 / contrast +6 | 让鳞片立起来 |
| 分离 | 02 背景退后 | sat −22 / clarity −12 / texture −8 / temp −6 | 苔藓去色降温，这是本案例的关键一刀 |
| 造光 | 03 斜射光带 | +0.16 EV / temp +4 | 从右上方下来的一道光 |
| 造光 | 04 光热点 | +0.14 EV | 光的落点 |
| 造光 | 05 白水压回 | −0.20 EV | 压住瀑布，别抢 |
| 造光 | 06 左下压暗 | −0.14 EV | 背光侧 |
| 造光 | 07 前景暗框 | −0.16 EV | 收视线 |
| 塑形 | 08 轮廓光 | +0.16 EV / clarity +26 | 靠 clarity 出效果，不是 EV |
| 塑形 | 09 下颌阴影 | −0.30 EV | 头部体积 |
| 塑形 | 10 颈部下缘 | −0.36 EV | 圆柱感 |
| 塑形 | 11 线圈下缘 | −0.36 EV | 圆柱感 |
| 塑形 | 12 左枝 | −0.30 EV | 圆柱感 |
| 塑形 | 13 右枝 | −0.28 EV | 圆柱感 |
| 塑形 | 14 眼睛 | +0.20 EV / clarity +25 | 眼神光 |
| 接触 | 17 接触影·U 底 | −0.18 EV | 压在苔藓上，不是浮着 |
| 接触 | 18 接触影·线圈底 | −0.18 EV | 同上 |

所有作用在主体上的层都是 **AI 主体 ∩ 几何框**（`MaskBlendMode=1` + 第二蒙版反相）。

### 实测

| 指标 | 原片 | 定稿 |
| --- | --- | --- |
| 主体/背景亮度比 | 2.36 | 2.13 |
| 主体−背景色差（R−B） | 27.1 | **41.5** |
| 背景饱和 | 0.795 | **0.623** |
| 主体饱和 | 0.807 | 0.795 |

### 复盘

- **成立的**：背景降饱和是这张的唯一解，因为苔藓绿和蛇的绿几乎同色，不拆饱和就没有分离。
- **差点翻车的**：一开始用 `ToneCurvePV2012` 直接 `--set`，写不进去（LR 会丢弃数组），
  必须用 `tree-set` 传列表。同理 `SharpenMask` 这个键不存在，正确是 `SharpenEdgeMasking`。
- **代价**：18 层里有 12 个 AI 蒙版时改裁切，LR 直接卡死 20 分钟。**层多了不要动裁切**。

## 案例 B：色相对立 · 草地里的杓兰

**照片**：大花杓兰一丛，长在绿草坡上，背景还有远山和天空。主体占幅 13%。

### 诊断（零状态实测）

- 粉花 vs 绿草：色相差约 142°，**色相刀成立**
- 花色 sat 0.58，草地 sat 0.36 —— 花更艳
- 亮度：花 96.5 / 草 106.5 —— 花反而更暗

→ 应该用**色相 + 冷暖光向**，明度只需不打架。

### 全局

```
CameraProfile = Camera Standard
Exposure2012  = +0.34
Contrast2012  = +3                  # 关键：只要 3，不要 8
Highlights    = −62, Shadows = +20
Whites        = −5,  Blacks  = −2
Vibrance      = 8                   # 正确键名是 Vibrance，不是 Vibrance2012
ToneCurvePV2012 = [0,0, 60,58, 128,130, 200,204, 255,255]
HSL: 蓝 sat +5 / lum −10；橙 sat +10；黄 sat +6    # 绿一律不动
```

### 12 层摘要

主体 4 层（花丛质感 / 顶部花受光 / 主花 / 主花下缘）+
背景 8 层（整体退后 / 天空渐变 / 阳光走廊 / 右侧光池 / 左侧背光 /
花丛后方压暗 / 前景暗框 / 左侧远山加雾）。

### 实测

| 指标 | 用户自己的版本 | 第一版（翻车） | 定稿 |
| --- | --- | --- | --- |
| 全图 / 中位 | 110 / 102 | 101 / **87** | 112 / 99 |
| 草地亮度 | 86 | **73** | 82 |
| 花部暗部 P10 | 43 | **32** | 45 |
| 粉/绿亮度比 | 1.21 | 1.39 | 1.37 |

### 复盘：这一版翻过两次车

**第一次（用户原话「压抑、更灰」）**：照搬了案例 A 的"背景降饱和"。
绿是这张的主色，抽掉绿就是抽掉颜色。加上 `Contrast +8` 两头夹中间调，
草地从 85 掉到 73。**同一个动作，一张是解药，一张是毒药。**

**第二次（用户原话「色彩发闷」）**：四个错误叠在一起——
① 给场景主色降饱和（绿 sat −4、背景 sat −5/−6）
② 高光压太狠 `−58` 而没有补曝光
③ 主体提亮过头（花朵层 +0.26 EV，花瓣 L 126 vs 用户版 108）
④ **`Vibrance2012` 这个键不存在**，自然饱和度一直是 0

结论：**发闷先查自己叠了什么，不要先怀疑原片**。

## 案例 C：分区处理 · 环境动物照（旱獭出洞）

**照片**：高原旱獭从洞里探头，广角环境照。前景草 + 中景草坡 + 远山 + 天空四层，
主体只占 4.2%。

### 诊断（归零后，这是最重要的一步）

| 基准 | 主体 L | 背景 L | 比值 |
| --- | --- | --- | --- |
| 带用户旧调整 | 150.7 | 112.6 | **1.34** |
| **参数全归零** | 116.3 | 114.0 | **1.02** |

按 1.34 会判「明度分离够了，不用管」；按 1.02 才知道必须靠色相和质感。
**差 33 个百分点，方案完全不同。**

→ 判定：明度 ✗、色相 ✓（暖褐 vs 绿，色差 16.1）、饱和反向、质感弱、焦点 ✗。

### 分区：背景用风光逻辑，主体用动物逻辑

| 区域 | 做法 | 参数 |
| --- | --- | --- |
| 天空 | **纯几何线性渐变**（不用 AI sky） | EV +0.02 / highlights −50 / sat −10 / temp +5；全局 HSL 蓝 sat −22、青 sat −10 |
| 左远山 | 加雾推远 | +0.06 EV / clarity −14 / dehaze −6 / sat −14 |
| 右近山 | 提层次拉近 | −0.05 EV / clarity +8 / contrast +4 |
| 中景光斑 | 放大照片里**本来就有**的那块（L 148 vs 周围 105） | 三层破形：主光斑 +0.11/feather 82；破形层 +0.09/feather 90；前缘压暗 −0.09 |
| 前景 | 压暗做框架，**不压 clarity** | −0.24 EV / sat −6 / temp −4 |
| 主体 | clarity 收到 4，靠阴影和投影做体积 | 头顶 +0.10 / 下颌 −0.18 / 身体背光 −0.20 temp −4 / 眼睛 +0.14 clarity 14 |
| **投影** | 落地感的关键 | 左侧草地 −0.22 sat −12；下方 −0.18 |

### 实测

| 指标 | 第一版 | 定稿 |
| --- | --- | --- |
| **主体高频 / 背景高频** | **4.47** | **3.52** |
| 天空饱和 | 0.28 | 0.13 |
| 中景光斑 / 周围 | 无 | 155 / 105 |
| 主体−背景色差 | 31.0 | 31.0 |

### 复盘（用户原话：两版）

**第一版「跟背景都不是在一个图层」**：为了突出主体把背景 clarity 压到 −14、
texture −9，主体 clarity 提到 14 → 锐度比 4.47。而且**没有投影**，
旱獭左侧草地和右侧一样亮，物体没有"落地"的证据。

**第二版「背景一点都没 P，天饱和度那么高」**：这次是反过来——
发现 **AI sky 蒙版的 alpha 实测只有 0.12**，挂在它上面的 EV/sat/highlights 只生效一成；
而压暗又让天空饱和从 0.16 涨到 0.28（分母变小）。换成纯几何渐变才真正压住。

**收获**：一张片子里同时有风光层和主体层时，**两套逻辑要往相反方向调锐度**——
背景要有层次（clarity 正），主体要贴合（clarity 小）。都往"更锐"走就会裂开。

## 三个案例的共同点

| 共同点 | 具体表现 |
| --- | --- |
| 都先归零再诊断 | 三次里两次的初始判断是错的，都是归零后才看清 |
| 都经历了至少一次翻车 | A：曲线写不进去；B：照搬降饱和；C：锐度断层 + 没投影 |
| 都靠差异图验收 | 不是看参数，是看 `|修后−原片|` 的形状对不对 |
| 都没有改构图 | 构图问题只写进报告 |
| 都留下"什么不成立"的记录 | 这比"什么成立"更值钱 |

## 如果你只想记一句话

> 每张图先问「它本来靠什么分开」，然后只放大那个。
> 没有的那个，不许硬造。
