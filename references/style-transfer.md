# 从教程提取风格

用户发来一篇教程、一组预设、一张参考图、一段视频字幕，说「照这个风格修」时，
用它。目标不是复刻参数，是复刻**决策**。

---

## 第 0 步：教程从哪里来（三种入口）

| 入口 | 触发说法 | 你要做的 |
| --- | --- | --- |
| **用户给了链接/文本** | 「按这篇修」「这个视频里那样」 | 直接进下面的五步法 |
| **用户只给了题材** | 「这张你看着办」「动物片一般怎么修」 | 自己搜，走本节的搜索流程 |
| **用户只给了一张参考图** | 「修成这张的感觉」 | 见文末「用户只给一张参考图怎么办」 |

### 自己搜的时候，怎么搜、怎么信

**关键词公式**：`<题材> + <具体难点> + post processing / editing`，
不要搜「怎么修图」这种大词。有效与无效的例子：

| 有效 | 为什么有效 |
| --- | --- |
| `environmental wildlife photography wide angle subject separation post processing` | 题材 + 难点（广角小主体分离） |
| `green snake on green moss editing subject background separation` | 同色系 → 搜索能命中"饱和/明度"这类真解 |
| `wildflower meadow photography flowers stand out editing` | 面积劣势主体 → 命中"光线/阴影池" |

| 无效 | 为什么无效 |
| --- | --- |
| `lightroom tutorial` | 无题材无难点 |
| `best editing settings` | 预设推销 |
| `how to edit like a pro` | 空话 |

**可信度分级**（只看这三条，不看排版好不好看）：

| 等级 | 特征 | 用法 |
| --- | --- | --- |
| **可采纳** | 2 篇以上独立来源说同一件事；给出"为什么"而不只是"拉多少" | 直接写进 `scene-diagnosis.md` |
| **可参考** | 单一来源，但解释得通 | 试一次，用本片数据验证 |
| **不采纳** | 只给数值、说"照做就行"、卖预设、无实拍对比 | 跳过 |

**只采纳被两篇以上独立来源同时提到的结论。** 单一来源当参考不当规则——
这条是从绿蛇/杓兰两次翻车里总结出来的：一个来源说"背景降饱和"，照搬到花田就废了。

**必须分辨"那张照片的解"**：教程作者的曝光值、去朦胧值、蓝通道明度，
全都取决于他那张原片。见下面一节的对照表。

## 核心区分：风格决策 vs 那张照片的解

教程里每一个数字都是「某个意图」在「某张特定照片」上的解。拆开看：

| 类型 | 例子 | 能否迁移 |
| --- | --- | --- |
| **风格决策** | 「高光压死，让云层有重量」 | 能，这是审美取向 |
| **风格决策** | 「阴影提到 71，保留暗部通透感」 | 能，这是取向 |
| **风格决策** | 「紫、品红拉到 −100，清杂色」 | 能，这是手法 |
| **那张照片的解** | 「曝光 −0.20」 | 不能，取决于原片曝光 |
| **那张照片的解** | 「去朦胧 +17」 | 半能，取决于雾有多重 |
| **那张照片的解** | 「HSL 蓝 −40 明度」 | 半能，取决于天空原本多亮 |

**迁移的是左列，右列必须按目标照片重算。**

## 五步法

### 第 1 步：拆解意图

读完教程，先用一句话写清「作者想让这张照片传达什么」，再列出他为此做的 3–6 个
**结构性选择**。

示例（一篇傍晚山谷教程）：

> 意图：让层叠的远山有空气感，同时保住前景岩石的质感。
>
> 结构选择：
> 1. 高光几乎压满（−98）→ 云层不炸，留出层次
> 2. 白场反而 +45 → 岩石质感提回来，不是一味压暗
> 3. 纹理、清晰度双降（−24 / −21）→ 抗过度锐化，画面柔
> 4. 去朦胧 +17 → 只用于分层远山，不是通篇加
> 5. 紫、品红 −100 → 清掉杂色，画面干净
> 6. 阴影 +71 → 暗部要透，不要死黑

注意：这些是**方向**，不是数值。数值是第 4 步才算的。

### 第 2 步：提取可迁移的结构

把上一步的每条翻译成「条件 → 动作」的规则：

```
如果 天空有云层且面积 > 25%      → 高光压低，压到云层细节保留但不炸
如果 前景有岩石/纹理              → 白场略提，保住质感，不要跟着高光一起压
如果 照片是无人机/高解析力         → 纹理、清晰度适度下调，避免过锐
如果 画面有远山层叠              → 去朦胧只加在远山层，不加全局
如果 画面有大量杂色（紫/品红）      → 该通道饱和拉到最低
如果 场景是逆光                  → 阴影不要提太多，剪影要保住
```

这张表才是真正要迁移的东西。它对任何照片都成立。

### 第 3 步：映射到目标照片

逐条检查规则的前提是否成立：

| 规则 | 目标照片满足吗 | 处理 |
| --- | --- | --- |
| 天空有云层且面积 > 25% | 满足，云占 40% | 应用 |
| 前景有岩石/纹理 | 满足，石滩占下半幅 | 应用 |
| 高解析力需降锐 | 满足，45MP | 应用 |
| 有远山层叠 | 满足 | 应用 |
| 大量紫/品红杂色 | **不满足**，画面干净 | 跳过 |
| 逆光 | **满足** | 阴影**不提**，反向下压 |

**不满足前提的规则必须跳过**，这是最容易被忽略的一步。
照搬「品红 −100」到一张没有品红的照片上毫无意义，照搬「阴影 +71」
到一张逆光剪影片上会直接毁掉片子。

### 第 4 步：按本片重算数值

现在才碰数字。方法：给每个参数定一个**目标指标**，从当前值反推。

```
目标：云层保留细节但不抢眼 → 高光压到云层最亮处 L≈235，不到 250
当前：云层最亮处 L≈252
反推：需要压约 17 个亮度单位 → Highlights ≈ −55 ~ −70
```

```
目标：远山比中景暗 30（逆光剪影）
当前：远山 110，中景 78
反推：远山要压到 48？不对——中景也会被全局改动影响，先定全局再定局部
```

**不要从教程的 −98 直接抄**。−98 是作者那张照片的云有多亮决定的。

同样，教程说「阴影 +71」，你要问的是「他为什么要提 71」——
答案是「他的暗部死黑占比太高」。你的照片暗部本来就够透，就不该提。

### 第 5 步：验证风格是否成立

修完导出，问三个问题：

1. **不看参数，只看画面**，能认出这是那个流派吗？
   （比如「明暗塑形派」的标志是分区明确、暗部有内容、光向一致）
2. **风格的核心特征还在吗**？如果教程的核心是「云层有重量」，
   你的成品云层是不是也有重量？
3. **有没有为了套风格而破坏原片**？如果目标照片是逆光，
   硬套顺光教程会让剪影消失，那就不是「风格迁移」是「削足适履」

前两条 yes、第三条 no，才算成功。

## 多个资料互相矛盾怎么办

> 用户要求：「多看点，多去网上搜点资料……但是每个资料之间它肯定都不一样，你不能弄混。」

不同来源打架时，按这个顺序裁决：

**1. 先看题材是否相同。**
鸟类站立姿态的「压尾侧、提头部方向」，套到盘曲的蛇身上就是错的——
蛇没有"尾侧"，它的受光面是每段的上缘。

**2. 再看软件能力是否够。**
Photoshop 教程里的「12.7px 高斯模糊」「High Pass 1.3px」「减淡工具 8% 不透明度」
在 LR 里没有对应物。硬套只会得到一个四不像。LR 的等效做法是
「单层 EV ≤0.25 + clarity/texture + 多层累积」。

**3. 再分清"风格"和"那张照片的解"。**
- 风格（能迁移）：压高光让云有重量、紫品红拉到底清杂色、去朦胧只加远山层
- 解（不能迁移）：他的高光是 −98，因为他那片云本身就爆了

**4. 最后看语种分野。**
中文微距/生态资料常强调「暗调氛围、轻微降对比」，
英文风光教程强调「高对比、压死高光」——这是两套审美体系，**不能取平均**。
先定这张片属于哪一类，再只采信那一类。

**实操**：把每个来源的每条参数标上 `风格 / 解 / 不可用`，只迁「风格」那一栏。
标记过程本身就是筛选，不要跳过直接抄数值。

## 风格流派速查

不同流派对同一场景的处理方向可能完全相反，先认流派再动手。

| 流派 | 核心手法 | 典型参数方向 | 适合 |
| --- | --- | --- | --- |
| **明暗塑形派** | 分区蒙版，一层管一个面 | 局部 EV ±0.2~0.4，清晰度局部加 | 有明确光向的场景 |
| **氛围/朦胧派** | 降对比、加雾、柔化 | 去朦胧负值、清晰度 −20、对比 −15 | 晨雾、雨天、抒情 |
| **高对比硬朗派** | 压黑场、提白场 | Blacks −30、Whites +40、清晰度 +25 | 岩石、建筑、强光 |
| **胶片模拟** | 曲线抬黑尾、色彩分级 | 曲线暗部抬到 15–25，阴影加青、高光加暖 | 人像、街拍 |
| **自然写实** | 只做校正，不做风格化 | 曝光/白平衡/镜头校正，HSL 微调 | 纪实、图鉴 |

判定方法：看教程里最极端的那个参数。
高光 −98 且阴影 +71（同时压两头）= 明暗塑形派在保细节；
清晰度 −21 且去朦胧 +17 = 氛围派在做空气感；
Blacks −30 且 Whites +40 = 硬朗派在拉对比。

## 输出格式

分析完教程后，产出一份这样的规格再动手：

```markdown
## 风格档案：<教程名 / 作者>

**流派**：明暗塑形派（分区蒙版）
**意图**：让层叠远山有空气感，保住前景质感

### 可迁移规则
1. 高光压满 → 云层留层次（目标：云最亮处 L<240）
2. 白场反向提 → 岩石质感回来
3. 纹理/清晰度下调 → 抗过锐（仅高解析力素材）
4. 去朦胧只加远山层
5. 阴影按光向决定：顺光提、逆光不提

### 本片适配
- 光向：右后方逆光 → 规则 5 反向：阴影**不提**，压 Blacks
- 远山：剪影处理，压到比中景暗 30
- 杂色：画面干净 → 跳过品红清理

### 参数（按本片重算）
| 参数 | 教程值 | 本片值 | 理由 |
| --- | --- | --- | --- |
| Highlights2012 | −98 | −56 | 本片云层未过曝，不需压那么狠 |
| Shadows2012 | +71 | +35 | 逆光片，提太多会毁剪影 |
| Blacks2012 | −21 | −9 | 已经压过一轮，避免死黑 |
| Texture | −24 | +12 | 本片细节适中，不需要减 |
```

**「理由」这一列必须有。** 没有理由的参数就是抄，抄出来的东西不成立。

## 反面案例

用户发来一篇教程，直接照搬全部参数后的典型失败：

- 教程是顺光海岸，目标是逆光山谷 → 远山被提亮，剪影消失
- 教程作者用无人机（过锐），目标是 45MP 单反 → 纹理降 24，画面糊
- 教程里「阴影 +71」因为他的片子死黑，目标片暗部本来就够透 → 整体发灰
- 教程「去朦胧 +17」通篇加，目标片本无雾 → 对比过头，暗部断层

共同点：**没有检查规则的前提是否成立**。

## 用户只给一张参考图怎么办

没有参数可拆，只能反推。步骤：

1. 测参考图的感知亮度梯度（分 8–10 个区域）
2. 测它的饱和度分布、色相偏好（阴影偏青还是偏暖，高光偏黄还是偏粉）
3. 测它的对比度曲线形状（暗部有没有抬、高光有没有压）
4. 把这些特征当成「目标指标」，套到自己的照片上
5. 用同样的闭环验证

这比拆参数更可靠，因为参数会骗人（作者的 LR 版本、配置文件、镜头都可能不同），
而画面不会。
