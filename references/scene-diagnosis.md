## 0.5 诊断必须在**零状态**上做，不能拿有旧调整的版本当基准

这条是拿真金白银换的（Z02_1488 青海旱獭）：

| 基准 | 主体 L | 背景 L | 比值 |
| --- | --- | --- | --- |
| 用户已有轻度调整的版本 | 150.7 | 112.6 | **1.34** |
| **参数全归零的零状态** | 116.3 | 114.0 | **1.02** |

同一张图，前者看起来「明度分离已经很强，什么都别加」，
后者才是真相：**明度几乎零差，只能靠色相和质感**。

如果按 1.34 做方案，会得出「不用管分离」的结论，直接做光影层；
按 1.02 做，才知道必须把预算全押在「暖冷色差 + 主体质感」上。
最终色差从 16.1 拉到 31.0，靠的不是明度而是色相——这个方向是零状态数据逼出来的。

**规矩**：`dump` 看到有非零参数（哪怕只是 `Exposure2012 = 0.14`），
先把全局归零、导出一张零状态图，再测诊断数据。
用户原有的调整要备份，测完再决定是恢复还是重做。

## 1. 第 0 步：数一数这张图有几把刀

分离主体和背景，物理上只有六把刀。**动手前先回答：这张图上有哪几把是真的存在的？**

| 刀 | 判据（本片是否成立） | 放大它的手段 | 用错会怎样 |
| --- | --- | --- | --- |
| **明度** | 主体和背景亮度差 ≥ 15%（Rec.709） | 主体提亮 / 背景压暗、局部核心阴影 | 明度差 <5% 硬拉 → 打灯感、贴纸感 |
| **色相** | 主体与背景在色轮上差 ≥ 45° | 让两侧朝相反方向走（饱和/明度），**不动色相本身** | 差 <30° 还硬拉 → 偏色、脏 |
| **饱和度** | 主体比背景更「浓」，或反过来 | 降背景饱和（**仅当背景不是画面主色**） | 背景是风景主色时降饱和 → 整张发灰 |
| **质感** | 主体有可辨认的纹理，背景是软的/散的 | clarity/texture 给主体，负值给背景 | 背景本来就虚 → 给负值是浪费 |
| **焦点** | 景深是否已经把背景分开 | 后期只能靠 clarity 近似，不能真虚化 | 已经虚了还压 clarity → 糊成一片 |
| **空间** | 主体轮廓周围有没有留白、有没有和背景元素相切 | 只能靠构图（**用户禁止改构图 → 这把刀不能动**） | 动裁切 = 越权 |

> 依据：`frameandfocal` 的宏观摄影研究——背景色相差 ≥45° 时人眼辨认主体快 1.7 秒，
> **即使亮度完全相同**；`kahibaro` 的构图课把它归成 Focus / Tone / Color / Space 四条。
> 两篇独立来源指向同一件事：先找已经存在的差异，再放大它。

**判断口诀**：
- **同色系**（绿蛇在绿苔上、棕鹿在枯草里）→ 用**饱和度 + 冷暖**，明度做辅助
- **互补色**（粉花在绿草里、红花在蓝天下）→ 用**色相**，明度只需要不打架
- **明度分离已经很强**（逆光剪影、白鸟在深林）→ 什么都别加，只做质感和层次
- **四把刀都不成立**（主体又小又同色又同亮）→ 老实说「这张的短板在拍摄端」，
  不要用十层蒙版硬造一个假的高光

## 2. 三类场景的完整对照（实测数据）

### A. 同色系 · 生态微距（绿蛇 / 绿蛙 / 竹节虫）

- 病灶：主体和背景同为绿，饱和度都 0.8，明度差 30% 左右
- 药方：**背景去饱和 + 降温**、主体 clarity、每段身体下缘压核心阴影
- 实测：背景饱和 0.816 → 0.623、主体−背景 R−B 色差 30.9 → 38.5
- 禁用：靠提亮主体硬顶（会被高光压缩吃掉，实测 +0.22EV 只出 +1.4）

### B. 色相对立 · 花田 / 花丛（杓兰 / 报春 / 杜鹃）

- 病灶：花只占 10–15%，背景是**大面积高饱和绿**，绿的「面积 × 饱和」压过花的「色相优势」
- 药方：**不动绿的饱和**（那是画面主色），改用
  1. 光的方向感：亮侧 temp +10~12、暗侧 temp −8，冷暖差推到 25 以上
  2. 主体周围一圈「阴影池」：−0.20~−0.26 EV，feather 40，配主体 +0.10~0.14
  3. 天空渐变（−0.28）、远山加雾（clarity −10 / dehaze −6）做纵深
- 实测：全图 101 → 112、草地 73 → 82、花部暗部 P10 32 → 45、冷暖差 32.6
- 禁用：Contrast 滑块（中间调被两头夹，草地立刻发闷）、绿通道大降饱和

### C. 风光（山、海、林）

- 病灶：缺大气透视、缺光向、天地比例失衡
- 药方：远山加雾（+EV / −对比 / 降温 / −dehaze）、光带 + 光池 + 反向压暗、
  前景暗框；云要有重量（压高光不是压亮度）
- 判据：`depth_qc.py` 的三项 + 分区亮度梯度
- 禁用：全局 Contrast 硬拉（层次会断）

### D. 人像 / 动物特写

- 药方：眼神光、轮廓光（clarity 为主，EV 为辅）、核心阴影、肤色分离
- 禁用：给皮肤加饱和（会脏）；背景压死（会假）

### E. 环境动物照（动物 + 广角环境，主体占 3–8%）

> 实例：Z02_1488 青海旱獭出洞（主体 4.2%，前景草 + 中景草坡 + 远山 + 天空四层）

- **诊断陷阱**：这类片子零状态下主体/背景明度差常常只有 2–5%（旱獭 1.02），
  但色相差通常有 50–70°（暖褐毛 vs 绿草）。**所以刀在色相，不在明度。**
  别按照"动物片就该提主体"的直觉走，一提就假。
- **药方**（实测有效顺序）：
  1. **主体加暖 + 提饱和**：`temp +3~+7`、`sat +3~+6`。
     实测主体 sat 0.25 → 0.30、R−B 30.1 → 36.8
  2. **背景降温 + 微降饱和**：`temp −5`、`sat −3`（草是主色，只能小动）。
     实测背景 R−B 14.0 → 5.8，**色差 16.1 → 31.0**
  3. **质感分离**：主体 `clarity 14 / texture 13`，背景 `clarity −14 / texture −9`
     （模拟浅景深。广角没有真虚化，这是唯一能做的"焦点刀"）
  4. 光影层 4–6 层就够：天空轻压、右侧光池、左侧背光、前景暗框、主体阴影池
- **禁用**：
  - 大幅压背景 EV（明度差不成立，压狠了主体和背景会「断开」）
  - 把主体 EV 提到 +0.15 以上（毛发高光立刻贴顶，旱獭胸口就白成一片）
  - AI Sky 做大范围压暗（见 pitfalls #37）
- **判断"够了"的标准**：色差 ≥ 25、主体 sat ≥ 0.30、亮度比 1.05–1.10 就停。
  再往上推，动物会像被打了闪光灯。

## 3. 强制调研步骤（新题材必做）

**遇到 skill 里没有对应条目的题材（兰花、菌类、鸟、昆虫羽化、水景……），
不许直接上手调参。先做这四件事，20 分钟内完成：**

1. **搜 3–5 篇**，关键词用「题材 + post processing / editing + 具体难点」，
   例如：`wildflower meadow photography post processing flowers stand out`
2. **拆成两类**（这是 `style-transfer.md` 的核心）：
   - **风格决策**（可迁移）：背景色相差 ≥45° 时人眼更快识别主体；
     阴影提升别超过 +18（绿色通道噪点）；用径向滤镜给主体 +0.45EV / clarity +22
   - **那张照片的解**（不可迁移）：他拍了背光所以压高光 −76；
     他的背景是天所以他降蓝饱和
3. **只采纳「被 2 篇以上独立来源同时提到」的结论**，单一来源当参考不当规则
4. **把结论写进本文件的对应分类**，带实测数字——下次同类题材直接查，不再重搜

**写下来的才算学到。** 只在对话里说一遍，下一张图必然重犯。

## 4. 交付前的三个测试（比任何指标都灵）

1. **缩略图测试**：把图缩到 300px 宽看一眼。主体还认得出来吗？
   认不出 = 分离失败，回去重做，别调参数。
2. **黑白测试**：转灰度看。如果主体和背景糊成一片，说明你只靠色相在撑，
   稍微换个屏幕或打印就崩。至少再补一层明度或质感。
3. **开关测试**：把某一层关掉再打开。**如果一眼看出差别、且看出「这是蒙版」，
   就太重了**；理想状态是关掉才发觉少了点东西。反例：重暗角、发光光晕 =
   一眼看穿是抠图。

### F. 环境动物照的**分区处理**：背景用风光逻辑，主体用动物逻辑

> 用户原话（2026-11-10）：「我建议你按照传统风光摄影的思路来处理这张图的背景部分以及前面的部分，
> 然后再用动物摄影的思路来处理这个动物部分。」

这是 E 类的进阶。第一版错在把整张当成"动物片"：只做主体塑形 + 把背景压糊。
用户的原话是「那个背景什么的一点都没 P 呢，天搞的饱和度那么高，又那么不过曝」。

**两套逻辑必须分开跑**：

| 区域 | 用什么逻辑 | 具体动作 | 禁用 |
| --- | --- | --- | --- |
| 天空 | 风光 | 压高光让云出层次、降蓝饱和（压暗会推高饱和，要同步降 sat）、上暗下亮渐变 | 用 AI sky 打底（alpha 只有 0.12） |
| 远山 | 风光 | 分层大气透视：远的加雾（+EV/−clarity/−dehaze），近的提 clarity/contrast | 一律压暗（会失去纵深） |
| 草坡 | 风光 | **找出照片里本来就有的光斑**并放大，不要新造一个 | 用单个径向做光斑（会露椭圆） |
| 前景 | 风光 | 压暗做框架，但保留纹理 | 压 clarity（会糊，和主体产生锐度断层） |
| 主体 | 动物 | 受光面亮、背光面暗、眼神光、**必须有投影** | 整只主体统一 +EV、把背景压糊来"突出" |

**这张的具体光逻辑**（写下来供同类照片参考）：
- 光斑不在"右侧"，而在**中景中部**（旱獭右侧草坡 L 148 vs 周围 105）——照片自己长出来的光
- 旱獭**头在光里、身在洞里**，这是真实关系，不要把它整只提亮
- 因为光从右上来，所以旱獭**左侧草地必须有它的投影**（−0.20 EV），这是"落地"的唯一证据

**验收三件套**：
1. 差异图里光斑是不规则柔团，不是圆/椭圆
2. 主体高频 ÷ 背景高频 ≤ 3.5
3. 主体在每个"背光方向"都有投影

## 5. 一句话总结

> 每张图先问「它本来靠什么分开」，然后只放大那个东西。
> 没有的那个，不许硬造。
